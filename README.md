# 🏥 リハビリテーション継続・離脱要因のデータ分析

本プロジェクトは、整形外科クリニックにおける患者のリハビリ継続・離脱に関わる要因（患者属性・臨床的因子・環境要因）をSQLを用いて抽出し、統計的検定（カイ二乗検定）およびダッシュボード化を通じて臨床的なアプローチの示唆を得ることを目的としたデータ分析ポートフォリオです。

---

## 📊 分析結果のサマリー（主要知見）

全1,000件の臨床データを分析した結果、**「疾患種別」「担当療法士」「年齢層」**の3因子が、リハビリ離脱率に対して**統計的に有意な影響（$p < 0.05$）を与えている**ことが明らかになりました。

### 1. 統計的に有意な離脱影響因子 ($p < 0.05$)

* **疾患別 ($p < 0.001$)【最主要因子】**
  * **筋筋膜性腰痛症（56.4%）**や**梨状筋症候群（50.0%）**など、痛みが主症状であり保存療法メインの疾患で離脱率が突出して高い。
  * 一方で、**TKA術後（11.5%）**や**骨折系（7.7%〜14.6%）**など、明確な治癒ゴールやリハビリプログラムが確立されている疾患は継続率が高い。
* **担当療法士別 ($p = 0.012$)**
  * PTごとの離脱率に **15.4% 〜 30.4%** の有意なバラつきが存在。
* **年齢層別 ($p = 0.024$)**
  * 40代（11.8%）を底として、**70代（28.6%）・80歳以上（38.6%）**と高齢になるにつれて離脱率が有意に増加する。

### 2. 統計的有意差は見られなかった因子 ($p \ge 0.05$)

* **就労状況 ($p = 0.238$)**: 無職（28.0%）と学生（16.7%）で数値上の差はあるものの、サンプル数の偏りもあり統計的な有意差には至らず。
* **通院距離 ($p = 0.150$)**: 10km以上（30.6%） vs 10km未満（24.2%）。距離による物理的ハードルは存在するが、単体での決定要因とは言えない。
* **性別 ($p = 0.084$)**: 男性（27.7%） vs 女性（22.8%）。男性の方が高い傾向（$p < 0.1$）は見られるが有意水準には達せず。

## 🛠️ 使用技術・ツール

* **Database / SQL**: MySQL / SQLite (TablePlus) — 条件別クロス集計・抽出クエリの作成
* **Data Processing & Analytics**: Python (pandas, scipy.stats) — カイ二乗検定（Chi-square test）による有意差検証
* **Visualization**: Excel Dashboard — 視覚的報告用ダッシュボードの構築
* **Version Control**: Git / GitHub — フィーチャーブランチ運用による開発管理

## 💡 臨床的考察と改善アクション案

1. **痛みを主訴とする疾患への患者教育・PSFS等の患者評価バッテリーを使用した効果判定の徹底**
   * 筋筋膜性腰痛症や梨状筋症候群の患者に対しては、月に一回困難動作の改善度合い・痛みを数値化しThと共有することでモチベーション低下の軽減、動作指導を積極的に図る。
2. **高齢患者（70代以上）に対するサポート体制の構築**
   * 独居率や通院手段の確認を初期評価に組み込み、通院頻度の調整やご家族との連携を図る。
3. **療法士間のリレーションシップ・技術の標準化**
   * 離脱率の高いPTに対してラポール形成におけるコミュニケーション力の向上、徒手的な治療技術・臨床推論の向上の図る。
